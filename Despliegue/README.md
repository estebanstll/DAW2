# Despliegue

Carpeta dedicada a la parte de despliegue del ciclo DAW. Aquí se concentra sobre todo documentación de apoyo, informes y entregables relacionados con la instalación y puesta en marcha de entornos de trabajo, servidores y servicios web. A diferencia de otras carpetas más orientadas a código, este bloque está pensado para dejar constancia de procedimientos, configuraciones y resultados de actividades técnicas.

## Qué trabaja esta carpeta

- Instalación y preparación de entornos web.
- Configuración de servidores y servicios habituales en despliegue.
- Documentación de prácticas y entregas de unidad.
- Material de apoyo sobre LAMP, Tomcat, TomEE y LDAP.

- [Esteban_Santolalla_Reinares_DAW_UD02_ACT2.docx.pdf](Esteban_Santolalla_Reinares_DAW_UD02_ACT2.docx.pdf): segunda entrega de la unidad 2.

- [Tomcat_y_TomEE_Esteban_Santolalla.docx.pdf](Tomcat_y_TomEE_Esteban_Santolalla.docx.pdf): documentación sobre Tomcat y TomEE, pensada para despliegue Java.

## Cómo leerla

Lo más útil es tomar esta carpeta como un archivo de evidencias y de procedimientos. Si buscas ver la evolución del bloque, sigue el orden de las entregas y utiliza [LDAP](LDAP/) como complemento cuando aparezcan conceptos de directorio o autenticación.

## Nota

La mayor parte del contenido es documental, así que este README funciona como guía rápida para ubicar cada entrega y cada documento sin necesidad de abrirlo todo uno por uno.
