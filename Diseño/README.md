# Diseño

Carpeta con material de diseño web, maquetación y recursos de apoyo. Está pensada para reunir ejercicios en los que importa tanto el resultado visual como la claridad de la interfaz. Aquí aparecen prácticas de CSS, accesibilidad, usabilidad, SEO y composición de páginas, junto con documentación teórica para entender mejor las decisiones de diseño.

## Qué trabaja esta carpeta

- Diseño visual y maquetación de páginas.
- Uso de CSS para estructurar y presentar contenido.
- Accesibilidad y experiencia de usuario.
- Revisión de prácticas centradas en menús, tablas, formularios y páginas completas.
- Documentación de apoyo para repasar HTML, CSS, SEO y usabilidad.

## Estructura

- [Accesibilidad](Accesibilidad/): ejercicios y material centrado en hacer interfaces más accesibles.
- [ApuntesCSS](ApuntesCSS/): apuntes y recursos para repasar CSS con más calma.
- [Edad input](Edad%20input/): práctica específica relacionada con la interacción mediante formularios.
- [Ejemplos](Ejemplos/): ejemplos reutilizables de formularios, menús, tablas y otros patrones de interfaz.
- [Ejercicio 3 1ª Evaluación TABLAS Y MENÚS](Ejercicio%203%201ª%20Evaluación%20TABLAS%20Y%20MENÚS/): ejercicio de la primera evaluación centrado en tablas y menús.
- [Examen](Examen/): práctica o contenido asociado a una evaluación de diseño.
- [pagina con bostrap](pagina%20con%20bostrap/): ejemplo de maquetación usando Bootstrap.
- [practica1](practica1/): primera práctica del bloque, útil como base inicial.
- [practica2](practica2/): segunda práctica, normalmente con más complejidad o más apartados.
- [REMARK](REMARK/): conjunto de páginas y recursos de una práctica más completa o cercana a un proyecto real.
- [Analisis SEO.pdf](Analisis%20SEO.pdf): documento de análisis SEO para entender aspectos de posicionamiento.
- [html_css_completo.pdf](html_css_completo.pdf): material de referencia sobre HTML y CSS.
- [LA PEREZA.pdf](LA%20PEREZA.pdf): documento complementario de apoyo o lectura.
- [Usabilidad.pptx](Usabilidad.pptx): presentación sobre usabilidad y criterios de diseño.

## Cómo usarla

Si lo que quieres es practicar, la parte más útil suele estar en [Ejemplos](Ejemplos/), [practica1](practica1/) y [practica2](practica2/). Si buscas teoría o repaso, ve a [ApuntesCSS](ApuntesCSS/) y a los PDF del nivel superior. Para accesibilidad y experiencia de uso, [Accesibilidad](Accesibilidad/) y [Usabilidad.pptx](Usabilidad.pptx) son los puntos más directos.

## Nota

Las carpetas suelen contener ejercicios autoexplicativos y los documentos PDF o PPT funcionan como apoyo teórico. Este README sirve como mapa rápido para encontrar qué tipo de práctica hay en cada bloque.
